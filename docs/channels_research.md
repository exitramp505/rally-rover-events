# Channels research (2026-10-18): Luma, Facebook Events, own page
Sources: luma.com/terms, help.luma.com (account review/appeals, featuring), Meta "Pages, Groups and Events" policies (2022 copy; check current version), Meta commerce policies. Web-summary level, not legal advice. Not re-verified against live Meta pages.

## Luma
- Terms: events are run by hosts; hosts are responsible for accuracy and content. Automated systems flag spam-like behavior, illegal content, harassment; flagged accounts get an email and an appeal path, and may be blocked from creating events (more forgiving than Eventbrite's lock).
- Prohibited (per a community-calendar guideline, not a platform-wide rule): events whose *primary purpose* is selling a product/token. Platform-wide, the risk is the same "spam" classifier.
- Discovery rules: featured events must be in-person, real venue, registration on Luma, host profile, clear description; no off-platform registration.
- Gaps: I found no explicit Luma rule on listing events you don't organize. Luma's model assumes the host controls the event, so a parade we don't run is a gray area.
- Risk: Medium. A "Meet up to watch the parade" listing with accurate details is much safer than a "fan guide RSVP page".

## Facebook Events
- Meta rules: Events must not impersonate or falsely represent an entity; if expressing support/interest it must make clear it is not official. Must not use deceptive business practices. Must disclose ticket costs. Edits must not mislead.
- Merch: Facebook Page/Shop and ads are governed by Commerce Policies and Advertising Standards. Posts linking to a store are allowed organically; ads for merch need an ad account and policy compliance. Heavy repeated promo to groups gets flagged as spam.
- Local community groups have their own rules; many ban selling posts or require admin approval. Ask first.
- Risk: Low to medium for a clearly labeled community meetup. Higher if the event looks like the official one (same name, flyer, "RSVP").

## Own page
- No platform risk. Only legal/trademark exposure: parade names are descriptive but may be trademarks; keep original art and a visible disclaimer. Printful store terms still apply.
- Best for permanence and SEO. Link out to the official page.

## Recommended framing (all channels)
1. Position as a community meetup/guide: e.g. "Watch the Georgetown Christmas Stroll Parade together" hosted by Rally Rover, not "the" event. Say plainly it is a public parade run by others; link the official page prominently.
2. Event title should not clone the official event page; add "Meetup" / "Watch Party" / "Guide" wording. The RSVP should be optional "I'm going" interest with no tickets or money.
3. Accurate date, time, address; copy only facts from the official source and update the same day if they change.
4. Merch: keep as a separate section lower down ("Take it home"), not the main purpose. Event description should be mostly useful info (parking, route, tips).
5. Disclaimer as the last line: "Independent fan guide and merchandise; not affiliated with or endorsed by the event organizers."
6. Don't use the organizers' logos, photos, or marks. Original art only.
7. Don't mass-post the same text across many groups or accounts. Post a few times, get admin permission in groups, and space it out.

## Honest risks
- The Eventbrite ban shows automated systems may flag third-party parade pages that link to merch. Luma and Facebook may do the same; no framing guarantees safety.
- A new Luma/FB account made only to avoid the ban may look evasive. Use the Luma account only once, with a real profile, and start with one event as a test. Don't create new accounts if flagged.
- An event that "Rally Rover" hosts at a public location with no organizer is technically a meetup we would be responsible for. Only list one if Lysander is OK with possibly actually showing up or posting it as informational.
- Facebook needs a personal profile to run a Page, and Lysander would have to log in. I won't run his personal account.
- Luma's featuring needs 5+ registrations and no outside ticketing links; the store link may reduce discovery.
- Printful W-9 is still declined; payouts aren't possible until fixed.

## Suggested order
1. Own site first (done, unpublished). 2. One Luma meetup as a test (Georgetown). 3. Facebook Page with event + posts, ask local groups' admins. 4. Watch for warnings; slow down at the first sign.
